# 圆角识别改进：第五轮结果

## 问题定位

第四轮报告显示 `bottle.brep` 有 49 个候选面、3 个连通分量，却被拆成 105 条路径。
`links.csv` 的连接类型统计为：

- 57 条公共边、G1、半径相容连接；
- 48 条无公共边、仅依赖共享支撑面对的复合连接。

检查逐面支撑集合后确认，旧逻辑把其他已接受圆角面也当成了结构支撑面。例如两个候选面
共同邻接两个圆角过渡面时，会被错误解释为“共同拥有两个母面”，从而生成伪复合连接。

## 修正

- 保留 `supportFaceIds` 作为全部切向邻面证据；
- 新增 `externalSupportFaceIds`，只包含未被接受为圆角候选的结构面；
- 共享支撑对补链只允许使用两个共同的外部结构支撑面；
- 链路汇总的支撑面数量也只统计外部结构支撑面；
- 新增链级 `ChainVerdict`。外部结构支撑少于两个的链标记为
  `needs-review-insufficient-external-supports`，并降低置信度，而不是冒充已验证工业圆角链。

## 解释

路径减少不等于准确率已经得到证明。bottle 剩余 25 条路径来自真实公共边图：其中 16 个节点
度数为 3，对应复合圆角在角部相交的拓扑。这里应保留分叉语义，不能为了减少数字而删除真实
G1 公共边。

IGES 模型现在更保守：拓扑断裂恢复出的候选面仍保留，但缺少两个外部母面的链会明确标成
“需复核”。下一步应依据人工真值模板计算候选面和链两级 precision/recall，再调整曲率场与
几何支撑恢复阈值。
