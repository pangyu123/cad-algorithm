# 圆角识别改进：第六轮结果

## 目标

第五轮已经能正确保留分叉图，但 `Path` 是拓扑分段，不等于一个独立 CAD 圆角特征。
本轮增加复合特征语义层，使调用方能够同时获得：

- 原始圆角候选面；
- 面之间的有类型连接；
- 最大非分支路径；
- 将多条路径和角部补片聚合后的复合圆角特征。

## 新增语义

候选面根据最终连接图的度数获得 `TopologyRole`：

| 角色 | 图定义 |
|---|---|
| `IsolatedPatch` | 度数为 0 |
| `TerminalPatch` | 度数为 1 |
| `BandPatch` | 度数为 2 |
| `JunctionPatch` | 度数大于 2 |

每个连通链聚合为一个 `Feature`，类型包括：

- `IsolatedPatch`
- `SimpleChain`
- `ClosedLoop`
- `CompositeJunctionNetwork`

`Feature` 保存所属面、带状面、端部面、汇合面、孤立面、路径 ID、外部结构支撑面、半径范围、
置信度和链级校验结果。报告新增 `features.csv`，`faces.csv` 新增 `topology_role`。

## 自环缺陷修正

OCCT 缝合边的祖先列表可能对同一面返回重复项。旧实现把列表直接转为数组，可能形成
`face -> same face` 自连接。本轮先对每条边的所属候选面去重，并增加自动测试禁止自环。

- 半径 2.5 的 24 面复合汇合网络：16 个带状面、8 个汇合面、12 条路径；

因此底层仍保留 25 条路径，但工程层输出为 3 个复合圆角特征，不再把路径数量误当作圆角数量。

## 边界

当前角色来自拓扑图结构，`JunctionPatch` 表示图节点度数大于 2，并不自动证明该面一定是
球形角部补片。后续仍应结合曲面类型、曲率方向和支撑面对变化，对角色做几何一致性验证。
