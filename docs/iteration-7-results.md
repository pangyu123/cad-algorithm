# 圆角识别改进：第七轮结果

## 新增能力

### 双曲率 B-Spline 角部候选

旧曲率场只接受次主曲率相对较小的“近似圆柱”曲面，会排除两个主曲率都显著的角部过渡面。
本轮保留两类曲率模式：

- 带状模式：次/主曲率中位比不大于 0.65；
- 双曲率角部模式：次/主曲率中位比不小于 0.65，且至少 80% 采样点的两个主曲率同号。

两类模式仍必须通过半径变异系数、有效采样数、支撑面和主曲面风险过滤。
逐面证据新增：

- `secondary_curvature_ratio`
- `same_sign_curvature_fraction`
- `double_curved`

### 几何—拓扑角色一致性

- `JunctionPatch` 期望球面、恢复球面或双曲率几何；
- `BandPatch` 期望圆柱、恢复圆柱、环面或单主曲率场；
- 孤立面和端部面仅凭图度数不足以确认角色，保持 `Unknown`；
- 发生冲突时标为 `NeedsReview`，记录 `role_reason`，Feature 置信度乘以 0.75。

Feature 报告新增几何角色是否完全验证、冲突面和未知面列表。

## 尚未解决

- 双曲率判定目前使用统计阈值，还没有验证曲率主方向沿路径的连续性；
- 环面在不同参数区域可能同时表现为带状过渡和角部过渡，需要局部曲率证据；
- 孤立面与端部面的角色需要边界曲线、支撑面夹角和截面圆弧共同判断；
- 没有人工真值前，新增的两个 CrankArm 候选只能称为有证据的候选，不能称为正确识别结果。
