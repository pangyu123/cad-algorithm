# 第二十二轮：逐连接方向证据与失败原因

## 目标

第二十轮的全局方向优化只输出整条路径总成本。总成本可以比较方案优劣，但不能回答“哪个面连接
出了问题、是空间间隙还是方向冲突”。本轮为最终选中的每一对相邻流线面建立可定位证据。

## 证据模型

每条方向转移记录：

- 所属轮廓和路径；
- 前后面 ID；
- 是否为闭环末端到首端；
- 中间跳过的路径面数量；
- 端点间隙除以模型包围盒对角线后的无量纲值；
- 已按全局方向翻转后的签名主方向点积；
- 与动态规划完全一致的转移成本；
- 是否通过质量门；
- 失败原因。

失败原因枚举：

- `none`：间隙和方向均通过；
- `unobserved-intermediate-faces`：两条流线之间存在没有轨迹的路径面，证据不足；
- `gap-too-large`：归一化端点间隙超过阈值；
- `direction-mismatch`：签名方向点积低于阈值；
- `gap-and-direction-mismatch`：两项同时失败。

默认阈值为：

- 最大归一化间隙：0.15；
- 最小签名方向点积：0.0。

阈值只对路径中直接相邻、两侧均有有效流线的面生效。中间存在解析面或缺失轨迹时，不把长距离和
方向变化误报为直接连接冲突。

## 关键结果

| 模型 | 通过 | 间隙冲突 | 方向冲突 | 中间证据缺失 |
|---|---:|---:|---:|---:|
| generated-closed-bspline-fillet-ring | 4 | 0 | 0 | 0 |
| CrankArm | 4 | 0 | 0 | 1 |
| bearing | 5 | 0 | 0 | 0 |
| linkrods | 7 | 0 | 0 | 8 |

其他模型的有效路径只有单个流线面或完全由解析面组成，因此没有逐流线转移。闭环真值件的 4 条证据
中恰好一条标记为 closure，4 条全部验证通过。

这组结果也解释了为什么不能直接对所有连续输出样本使用统一间隙门：CrankArm 和 linkrods 部分
流线之间隔着没有采样的解析圆角面，必须先报告证据缺口，而不是判为几何不连续。

## 回归

测试除默认闭环 4/4 通过外，还使用两组强制阈值验证失败分支：

- 将最大间隙设为 0，必须定位全部 4 条闭环转移为间隙冲突；
- 将最小方向点积提高到 0.999，必须产生可定位的方向冲突。
