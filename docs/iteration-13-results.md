# 圆角识别改进：第十三轮结果

## 受控 Sewing 对比

新增 `compareWithSewing()`，它不会替换调用者提供的 Shape，而是返回：

- 原始 Shape 的完整识别结果；
- Sewing 副本及其完整识别结果；
- Sewing 容差和自由边、连续边、多重边、删除面统计；
- 原始面到修复后面的映射；
- 修改面、映射面数量。

CLI 新增：

- `--compare-sewing`
- `--sewing-factor <positive number>`

默认安全限制：

- Sewing 仅显式启用；
- 容差不超过模型包围盒对角线的 `1e-5`；
- 禁止非流形 sewing；
- 不切割自由边；
- 原始和缝合结果分别写入 `original`、`sewn` 子目录；
- 额外导出 `sewn-shape.brep`、`sewing-comparison.csv` 和
  `sewing-face-mapping.csv`。

## bearing.iges

保守默认配置结果：

| 指标 | 原始 | Sewing 副本 |
|---|---:|---:|
| 面 | 213 | 213 |
| 边 | 941 | 515 |
| 接受候选面 | 41 | 153 |
| 链 | 37 | 55 |
| Feature | 37 | 55 |
| Shape 有效 | 是 | 是 |

Sewing 容差被尺度上限限制为约 `1.61424e-6`。Sewing 报告49条自由边、438条连续边、0条
多重边；213个原始面全部映射，全部被 OCCT 标记为修改。

缝合后大量原来因支撑不足被拒绝的曲率候选获得了拓扑支撑，从41个升到153个。这不等于
准确率提高，也可能把原本独立的自由曲面组织成大量伪圆角候选，必须通过真值判断。

## hammer.iges

| 指标 | 原始 | Sewing 副本 |
|---|---:|---:|
| 面 | 45 | 45 |
| 边 | 208 | 104 |
| 接受候选面 | 15 | 0 |
| 链 | 15 | 0 |
| Feature | 15 | 0 |
| Shape 有效 | 是 | 是 |

Sewing 后37个面被判为不满足几何候选，8个面因支撑不足被拒绝。原始结果中的15个候选全部
消失，说明原先基于断裂拓扑的几何恢复结果高度可疑，同时也说明 Sewing 会改变裁剪/pcurve 和
曲率采样行为，不能作为无条件预处理。

## 结论

Sewing 对 bearing 和 hammer 的影响方向完全相反。这正是必须保留 A/B 结果、面映射和修复后
Shape 的原因。当前版本只提供诊断和显式对比，不会自动选择“原始更好”或“缝合更好”。

## 尚未解决

- 当前整形 Sewing 仍可能跨 Compound 顶层组件建立关系；下一轮需要按实体/壳分区处理；
- 面映射支持一对多，但还需要记录无法映射和多对一冲突；
- 需要把自由边长度、最大缝合 gap 和壳闭合性加入安全门；
- 没有人工真值时不能根据候选数量决定是否采用 Sewing 结果。
