# 第二十轮：路径级全局方向一致性

## 目标

此前路径样本按“当前面离上一面哪个端点更近”逐面贪心翻转。局部最优不能保证整条长链最优，
闭环还完全没有考虑末端与首端的闭合关系；分叉路径的起止方向也受面遍历顺序影响。本轮将图路径
方向规范化，并用动态规划一次性求解整条路径的流线方向。

## 实现

### 路径规范方向

- 只有一个分叉端点的路径统一从分叉节点向外；
- 两端同为分叉或同为非分叉的开放路径，用端点稳定几何 ID 决定方向；
- 闭环旋转到稳定几何 ID 最小的面作为根；
- 闭环根的两个邻面再按稳定 ID 排序，得到确定的环向；
- 路径翻转时同步交换起止节点和分叉标志。

### 全局流线翻转

每个有采样的自由面有“保持”和“反转”两个状态。相邻状态转移代价为：

`端点三维距离 / 模型对角线 + 0.10 × (1 - 有向主方向点积)`

动态规划保留每一步两个状态的最小累计代价及父状态。开放路径允许首面两个方向竞争；闭环分别固定
首面两个方向求解，并将末面到首面的闭合转移加入总代价。最终统一反转样本顺序及主方向符号。

报告新增：

- 是否执行全局方向优化；
- 参与优化的流线面数；
- 被反转的流线面数；
- 全局方向总代价；
- 贪心方向基线代价；
- 闭环首尾三维间隙。

19 条包含多个流线面的轮廓执行了全局优化，共翻转 21 个流线面。现有开放链数据上全局解与改进后的
贪心基线恰好同代价，但全局解从算法上保证不更差；所有报告均满足
`orientation_transition_cost <= greedy_orientation_transition_cost`。

八个模型中共有 47 条路径触及分叉，最终没有任何路径出现“终点为分叉而起点不是分叉”的反向情况。
半径行为分类、接受面、链和路径数量均与第十九轮一致。

## 回归与限制

Visual Studio 2019 Debug 构建成功，`ctest` 结果 1/1 通过。回归测试检查：

- 全局代价不高于贪心代价；
- 翻转面数量不超过参与优化面数；
- 单分叉端路径始终从分叉点向外；
- 闭环根和环向满足稳定 ID 规范。

当前八模型库没有形成由多个已接受圆角面组成的闭合图路径，因此闭环动态规划分支已实现并有结构
断言，但还缺少真实闭环真值件的运行覆盖。这是下一轮测试数据建设的明确缺口。
