# 圆角识别改进：第十轮结果

## 无共享边复合连接的方向证据

识别器仍只接收 `TopoDS_Shape`。当两个候选面没有共享的 `TopoDS_Edge`，但已经满足以下复合
连接条件时，本轮尝试补充方向证据：

- 空间包围盒邻近；
- 半径相容；
- 至少两个共同的外部结构支撑面。

算法从两个面的裁剪边界双向采样，将空间点投影到另一曲面，随后检查：

- 投影 gap 不超过自适应几何恢复容差；
- 投影 UV 位于目标裁剪面的 `IN` 或 `ON` 区域；
- 两侧主曲率均有效；
- 样本不位于近脐点区域。

满足条件的样本再比较次曲率主方向。计算预算由
`maximumProjectedDirectionAttempts` 限制，默认每个候选面对应最多 100 次投影尝试。

## 证据来源与审计

新增 `DirectionEvidenceSource`：

- `None`
- `SharedEdge`
- `ProjectedBoundary`

`links.csv` 现在保留每个有效样本的：

- `spine_direction_alignment_samples`
- `spine_direction_projection_gap_samples`

这样最小值异常可以回溯到原始采样证据，而不是只看到汇总分数。

## bearing.iges 结果

第九轮中 bearing 没有可用的共享边方向证据。本轮对 6 条进入图的复合连接全部获得 5/5 个
有效投影样本：

- face 26–37、26–39、26–62、37–39、37–62 的最小 alignment 接近 1；
- face 45–67 的 5 个 alignment 为约 `1、1、1、1、0.000027`；
- face 45–67 的投影 gap 约为 `2.07e-9` 到 `3.92e-9`，远小于有效线性容差，异常不是由大间隙投影造成；
- 该连接因此被标为方向冲突，所属 Feature 置信度从 0.7 降为 0.56，但连接和候选仍被保留。

最后一个样本可能表示局部主方向旋转、参数分支切换或接近尚未被 0.90 阈值排除的方向不稳定区，
需要结合面可视化和人工真值复核，不能仅凭一个样本删除连接。
