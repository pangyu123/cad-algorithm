# 圆角识别改进：第三轮结果

## 新增能力

- 对拓扑不共边的边界，使用包围盒邻域、边中点投影、曲面 gap 和法向夹角恢复几何切向支撑面；
- 每面和每模型均设置恢复预算，避免 IGES 上出现无界的 edge-face 距离计算；
- 推断支撑面与拓扑支撑面分开记录；
- 将候选面图分解为最大非分支路径、纯闭环和连接分叉节点的路径；
- 共享支撑面对连接增加空间邻近约束。

## 结论与风险

- 几何支撑恢复使两个 IGES 模型从完全无法接受候选变为可输出待确认链路，且预算优化后能在秒级至十余秒内完成。
- 所有通过几何恢复的 IGES 面置信度为0.7，低于完整拓扑证据，不能直接作为确定圆角。
- screw 没有推断支撑，说明其失败不是简单的 STEP 断边间隙。
- bottle 的两个24面分支网络被拆为105条最大路径；空间邻近约束未改变该结果，说明高连接度来自公共边图。需要导出具体图关系并结合人工真值判断，不能武断剪枝。
- 当前稳定 face ID 只在单次 shape 映射内稳定；跨导入、跨修复和装配实例的持久标识尚未解决。
