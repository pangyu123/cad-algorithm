# 圆角识别改进：第二轮结果

## 新增能力

- 对一般 BSpline/Bezier 曲面进行面内网格采样；
- 计算两条主曲率，选择主导横截曲率并统计局部半径；
- 用半径变异系数和次曲率比过滤非 canal-like 曲面；
- 输出局部最小/最大半径和 `variableRadius`；
- 根据面方向和主曲率符号输出初步凹凸性证据；
- 使用圆柱角度覆盖、面积占比、半径/模型对角线三个信号识别主体曲面风险；
- CLI 输出几何、支撑不足和主体面风险三类拒绝统计。

## 当前判断

第二轮同时验证了两点：曲率场能补出 CrankArm、Pump_TopCover 和 Motor-c 的一般曲面候选；主体面风险组合判据能把 bottle 从第一轮53面恢复到原基线的49面。尚无人工真值，因此新增结果仍只能视为待确认候选。

下一轮应优先导出逐面证据和几何，以便人工标注；同时修复 IGES/STEP 中支撑面关系缺失，并把连通分量进一步分解为最大非分支路径、闭环和分叉节点。
