# 第二十三轮：Feature 三态证据与置信度聚合

## 目标

此前 Feature 置信度来自链平均值和少量隐式乘数，无法明确区分“已经验证”“发现冲突”和“只是
缺少证据”。本轮将拓扑、半径和方向证据分别聚合为三态，并公开最终置信度公式及全部分项。

## 三态定义

- `validated`：该维度需要的证据存在且全部通过；
- `conflict`：存在明确的几何、半径或方向矛盾；
- `insufficient-evidence`：没有明确冲突，但证据覆盖不足。

总状态取三项中最严重者，严重性顺序为：`conflict > insufficient-evidence > validated`。

## 三个证据维度

### 拓扑与支撑

- 链有足够外部结构支撑，且所有面几何角色一致：通过；
- 存在几何角色冲突：冲突；
- 支撑不足或角色仍未知：证据不足。

### 半径稳定性

- 解析半径或自由曲面跨种子结果稳定：通过；
- 存在跨种子不稳定或低对齐轨迹：冲突；
- 变半径行为、种子数量或轨迹覆盖不足：证据不足。

### 路径方向

- 共享边/投影方向或逐流线转移均通过：通过；
- 存在连接方向冲突、端点间隙冲突或流线方向冲突：冲突；
- 方向采样覆盖不足、跨过未采样中间面，或多面 Feature 没有方向证据：证据不足；
- 单面 Feature 不需要跨面连续性，视为方向通过。

## 置信度公式

保留原链置信度为 `base_geometry_confidence`：

`最终置信度 = 基础几何置信度 × 聚合证据分数`

默认聚合分数：

`0.40 × 拓扑分数 + 0.30 × 半径分数 + 0.30 × 方向分数`

默认三态分数：

- 通过：1.00；
- 证据不足：0.65；
- 冲突：0.35。

权重与分数均已放入 `Options`。权重自动归一化；要求非负且总和大于 0。三态分数要求
`0 <= conflict <= insufficient <= validated <= 1`，非法配置会抛出参数异常。

## 报告与回归

`features.csv` 新增四个状态、三个分项分数、聚合分数、基础置信度、半径异常轮廓数量和方向异常
连接数量。命令行同时汇总三态 Feature 数量和平均最终置信度。

回归测试验证：

- 完整闭环三项通过时最终置信度等于基础几何置信度；
- 强制制造方向间隙冲突后，总状态变为冲突且置信度下降；
- 将方向权重设为 1、其余权重设为 0 时，最终值精确等于基础值乘冲突分数；
- 默认配置和全部既有识别拓扑保持稳定。

Visual Studio 2019 Debug 构建成功，`ctest` 结果 1/1 通过。完整报告位于
