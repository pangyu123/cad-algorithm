# 第十六轮：沿主方向恢复采样半径函数 R(s)

## 目标

上一轮只有逐面名义值和曲率网格的最小/最大值，不能判断一个面内的半径如何变化。本轮在
曲率场带状候选上恢复一条可定位的采样轨迹，并直接从有序序列判断半径行为。

## 实现

1. 在曲率网格的每个有效点求两条主曲率方向；
2. 比较主脊线方向与曲面的 U/V 一阶导数，投票确定脊线主要沿 U 还是 V；
3. 选择有效样本最多且最靠近曲面中部的横截行；
4. 沿该方向独立密集采样 11 点，并执行面内裁剪、曲率和脐点有效性检查；
5. 用三维点间弧长将参数归一化到 `s∈[0,1]`；
6. 跨面路径按相邻端点距离自动调整每个面采样序列的方向，再生成路径级 `R(s)`；
7. 使用全局变差、有效变化步比例、单调方向一致性、最大单步占总变差比例，以及跨面跳变共同
   区分 constant、smooth-variable、segmented 和 discontinuous。

新增审计输出：

- `face-radius-samples.csv`：逐面原始采样；
- `radius-profile-samples.csv`：按路径重新排序和归一化后的采样；
- `radius-trace-points.brep`：采样点；
- `radius-trace-segments.brep`：采样轨迹线段；
- `radius-profiles.csv`：增加样本数、最大样本跳变、总变差、主导步比例、有效步比例和单调比例。

## 真实变半径回归件

测试使用 OCCT 7.8.1 的 `BRepFilletAPI_MakeFillet::Add(3.0, 8.0, edge)` 在盒体边上生成
变半径圆角，并保存为：

`D:\workspace\cad-algorithm-build\debug\test-artifacts\generated-variable-fillet.brep`

识别结果：1 个接受面、1 条链、1 条路径、11 个 R(s) 样本，行为为
`smooth-variable-candidate`。采样起止半径为 3.11519 和 7.88699；有效变化步比例 1.0，
单调比例 1.0，最大单步只占总变差 0.121737。它证明较大的总半径变化并不等于分段或断跳。

回归测试现在明确要求这个 3→8 圆角必须输出单调参数化轨迹，并分类为平滑变半径；结果 1/1 通过。

## 尚未解决

- 当前轨迹是参数域中根据主方向选择的中部采样行，不是严格求解出的微分几何 ridge 曲线；
- 强扭曲参数化、轨迹跨越裁剪孔或主方向在面内旋转时，需要流线积分而不是固定 U/V 行；
- 多面路径的方向目前按端点距离确定，闭环路径还需要全局方向优化；
- `Motor-c` 的 8 条 min/max 变化路径没有足够的有序轨迹证据，已明确降级为
  `insufficient-evidence`，不再冒充平滑变半径；
- segmented 是需要复核的几何行为，不能直接解释成 CAD 建模历史中的分段半径命令。
