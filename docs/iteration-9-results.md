# 圆角识别改进：第九轮结果

## 沿边多点方向采样

第八轮只检查公共边中点，无法发现长边局部扭转。本轮默认在每条有效公共边的参数区间内取
5 个内部样本，位置为 `1/6、2/6、3/6、4/6、5/6`，避免直接落在端点奇异位置。

每个 Link 记录：

- 请求样本数和有效样本数；
- 有效覆盖率；
- 脊线方向 alignment 的最小值、均值和标准差；
- 是否达到方向一致性阈值。

默认至少 60% 样本有效才形成方向结论。有效后使用最小 alignment 与 `cos(15°)` 比较，
因此局部单点扭转不会被平均值掩盖。

## 脐点保护

当某个采样点两个主曲率的绝对值非常接近时，主方向在数学上不稳定。若
`min(abs(k1), abs(k2)) / max(abs(k1), abs(k2)) >= 0.90`，该样本会被跳过。

Feature 分别记录：

- 方向冲突 Link；
- 有效覆盖不足 Link；
- Feature 最小与平均 alignment；
- 平均样本覆盖率；
- 是否完整通过方向验证。

覆盖不足保持未知，不会被错误算成通过；方向冲突继续保留候选并降低置信度。
